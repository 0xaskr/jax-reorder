# 无根计算、对称接口与深层区域

完整图比较保留未参与输出的纯计算和未使用常量。它们的数量、内容、连接和共享仍属于图语义；不能通过 DCE 把它们删掉后报告等价。

## 有序根之外的编号

可达节点继续使用输出/有序操作根决定的 BFS 编号。其余节点与常量进入同一张带标签的图：标签包含完整节点语义及固定外部输入，边记录操作数端口、结果端口、常量绑定和顺序约束。细化同时查看前驱和后继，保留与可达部分的共享，不把组件单独比较后丢掉共同来源。

细化仍有平局时，对候选分组做个体化和精确连接搜索，选择规范排列。只有邻接表完全相同的孪生顶点才能共用搜索代表。不会把“细化颜色相同”当作同构证明；四节点环形共享与两组独立二节点共享的反例会判为 `different`。

多个全分支未使用的内部形参，或多个未使用的调用结果，没有首次使用路径可直接排序。实现对允许角色内的槽位置换进行有界搜索，以整张父图的完整表示选择结果。只改变一侧绑定的候选仍不能通过原始图复核。

`search_budget` 默认 10,000。无根图搜索以个体化状态计数，接口搜索以完整规范化尝试计数；预算分别限制每张区域图与最外层接口搜索，嵌套总成本也会随区域数量增加。预算不足会给出节点/常量或歧义槽位规模并返回 `unknown`，不能回退成任意顺序再报告图不同。枚举数量超限时提前结束，不先生成全部排列。

排序键仅用于决定顺序；最后比较完整结构，并检查原始图双射。含类型、Primitive、PRNG 实现身份的表示是进程内表示，不是持久化交换格式。

## 深度与执行

区域规范化通过显式生成器工作栈逐个完成子图。参数编码、参数中子图替换、对应证据构造与图差异诊断也使用显式栈。共享区域及重复的对应子问题缓存复用，避免把共享 DAG 展开成指数规模的树；异常路径按栈的逆序恢复 mesh 和轴环境。

可执行图仍按依赖深度与规范编号排列。孤立节点放在可达部分之后，在孤立部分内部同样保持依赖。返回值中的 `unused_equations`/`unused_constants` 保留诊断索引，存在这些索引不再意味着结果未完成。

[区域压力测试](../../tests/test_depth.py)区分 8、16、32 层共享混合区域与 2000 层参数容器；[图规模测试](../../tests/test_stress.py)另验证 6000 节点依赖链和 512 路扇出。JAX 自身的追踪、类型检查和编译仍有资源限制，这些有限压力测试不构成无限规模保证。

[完整图测试](../../tests/test_unrooted.py)保留 AI 手写的改写函数、共享关系反例、未使用常量及预算拒绝路径。它们没有用脚本生成候选改写。
