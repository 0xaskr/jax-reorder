开发文档应覆盖：

- 问题与输入输出契约：签名、静态参数、常量、dtype、shape、pytree 与 effects。
- 支持范围和拒绝条件，结构模式与代数模式的区别。
- 表示与算法：依赖关系、确定性要求、复杂度、替代方案和已知局限。
- 验证：正例、反例、失败案例、环境版本、复现命令与结果。
- 证据与进展：假设、已确认结论、未解决问题及对应计划。
