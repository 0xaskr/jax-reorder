日期：2026-10-15。状态：首轮并行评估、真实 jaxpr 局部转换及检查完成。

本文保留评估阶段的实验结果。后续 SymPy 正式接入、独立证据复核、实数多项式负证据和

## 用户目标与评估口径

仓库的目标是对两份 JAX 程序给出计算图等价、数学等价、数学不等价或 unknown。模型 layer 与手写改写是检验这个通用比较器的真实输入；对象是带完整算子语义的拓扑和数学表达，不是模型运行后的数值相似度。计算图比较已有实现，本次聚焦数学推理的社区复用。

实现语言和 IR 均可转换。不能只保留无标签的连边：轴、shape、dtype 解释、常量、mask、索引、区域绑定及有序输出仍属于数学程序。数学不等价指两者不是同一函数，并不要求每个输入都不同。缺少规则、转换失败、超时和未完成证明均保留 unknown。

“所有热门”在本轮落实为覆盖六类技术路线的 21 个项目/组件清单，不声称穷尽所有社区项目。候选按与需求的关系评估，而非按 star 数决定可靠性。评估分为实际运行、源码核对、文档核对和环境受阻；未构建不等于算法失败。

计划先写入仓库后，三个 subagent 分别评估等式饱和、张量证明/SMT、CAS，主代理评估编译器路线并生成真实图清单。分组结果再交叉审查。详见[执行计划](../exec-plans/completed/open-source-equivalence-backends.md)。

## 当前建议

1. **先验证 SymPy + cvc5/Z3 与现有索引 IR 的组合。** SymPy 提供现成标量、矩阵和求和变换；SMT 提供条件推理与精确反例。双方仍需要有语义依据的 JAX 转换与全图组合，不能仅安装依赖就解决整层。
2. **TASO、SPORES、TensorRight 优先作为张量定义和规则来源审计。** 已找到直接相关的缩放、收缩和求和规则；但各自存在语义范围、固定 shape 或运行/源码问题。
3. **egg/egglog 是扩展多步搜索的候选。** 本次现成数组规则没有完成 E2/E3/E4，证明能力主要取决于给它的规则。先衡量规则复用收益，再决定是否增加搜索引擎。
4. **TVM 可辅助索引范围；MLIR/StableHLO 可辅助转换。** 它们不直接补齐完整数学等价判定。

本轮没有候选完成整个 GLM 的十组外部证明。正例的小型符号证明、局部负例、库自带测试和真实整层证明分别记录。此前仅根据项目定位优先推荐 TensorRight 的判断，经源码及覆盖核对后已调整为“规则来源和后续审计候选”。

固定维度的符号变量可以证明该维度下的普遍等式，它不是随机数值测试；但不能因此声称任意维度。精确反例也不是数值相似度测试，其意义是反驳指定数学义务；仍须证明它满足完整源程序的约束。

## 真实 GLM 与探针之间的距离

[抽象清单脚本](../../tools/experiments/equivalence_backends/glm_inventory.py)已追踪原始及十个候选的 glm/FP32 签名，禁止后端编译和 eager 数组运算。原图递归 196 条方程，全体 33 种 primitive。完整清单与复现命令见[编译器报告](equivalence-backends/compiler.md#真实-glm-图覆盖清单)。

追加的[真实 jaxpr → SymPy 探针](../../tools/experiments/equivalence_backends/cas_jaxpr_probe.py)直接追踪 GLM 文件中的原始/改写 helper，读取各自的 primitive、batch/收缩轴、广播与归约参数，并转换为带自由索引和绑定求和的表达式。采用真实 glm 尺寸，未枚举所有张量元素：

| 实际 JAX 程序对 | 结果 | 证据范围 |
| --- | --- | --- |
| `_qk` / `_qk_scale_first` | 数学等价 | 收缩长度 576，两个索引求和规范式相同 |
| `_pv` / `_pv_reduce` | 数学等价 | token 维 2048，真实 batch/head 轴保留，两个索引求和规范式相同 |
| `_qk` / `_qk_without_scale` | 数学不等价 | 取合法的均匀符号输入族，输出差为非零多项式 `-540*x*y` |
| 两个 JAX 分配律写法 | 数学等价 | 从各自 jaxpr 转换后符号展开相同 |
| 未适配的 JAX exp | unknown | 转换器明确拒绝，未忽略算子 |
| 空输出轴 | unknown | 交叉审查发现自由索引空域风险后增加正维度拒绝，未据形式残差误报不等价 |
| 两个不同的精确常数输出 | 数学不等价 | 修复无生成元多项式路径异常后，直接使用精确非零常数差 |

这里新增的是一个**本次手写的受限转换器**；社区复用部分是 SymPy 的精确表达式和变换，不宣称 SymPy 已有 JAX 前端。它绕开了通用数组互转的共享 batch 问题，直接保持自由索引。结论限定于正大小静态维度、固定 FP32 签名的有限实数解释，无 dtype 改变；标量允许，dtype/shape、pytree 与输出顺序检查保留。编译/eager、`Expr.equals` 和随机探测路径均阻断。

PV helper 的输入被建模为独立有限实数张量；完整 layer 中该输入来自 masked-softmax，相关桥接尚未建立。因此它证明了这条局部接入路径可用，没有把当前 GLM 的整层 unknown 改为通过。主要组合缺口是：

- batch/contract/free 轴、广播、reshape 与动态索引必须保持完整数学含义。
- `-inf` mask、`reduce_max`、exp、div、全 mask 防护之间需要条件推理，不能仅声明输出有限。
- `top_k` 与 `approx_top_k` 的索引、并列和参数必须保留；不能因共同算子名就忽略其输入关系。
- `scan`、jit、custom JVP 等嵌套区域必须与现有绑定/循环契约组合。
- 数学不等价证据必须作用于最终有序输出，不能把某个中间义务失败直接报为“完全不等价”。
