## 授权前已确认的边界（历史）

设计中的三处规则相互一致：

- [代数 lowering](../../design-docs/current/algebraic-equivalence.md)明确要求：
  “结果未使用的未初始化读取仍拒绝”。
- [Pallas 契约](../../design-docs/current/pallas/contracts.md)明确要求：
  “删减不能跳过读取初始化、地址合法性或通信义务检查”。
- [内存规则](../../design-docs/current/pallas/grid-memory.md)拒绝 scratch/output
  的 active 未初始化读取。

因此，直接删除原始 `get` 或跳过初始化检查会改变契约。已用单独命名的
shape 初始化候选研究后续能力，原始 base 的拒绝证据继续保留。

2. **比较的输出边界**：当前设备局部范围比较全部九个 kernel 端口，不能悄悄改为
   launcher 的六个公开输出。若需要后者，应明确提供可观察输出选择和完整父图的
   依赖证据，保留全部实际写入、地址与通信义务；默认全端口契约不变。涉及上述

   已初始化的版本作为独立候选测试。
   尾窗新证据还表明，单独缩小输出选择不能豁免实际 DMA 的源初始化要求；
   若要保留原始尾窗源码，必须另行评审仅流向不可观察填充区域的本地 DMA
