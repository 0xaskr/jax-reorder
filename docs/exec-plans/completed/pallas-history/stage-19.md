### 9.19 Grid 并行批量轴与串行状态展开（2026-10-20）

状态：本子阶段实现及验证完成。用户要求解决自动访存、资源共享及展开规模
三项；下方记录具体实现、验收证据和保留条件。

用户提出在语义图阶段展开 grid：纯并行轴加入值的批量形状，纯串行轴复制
kernel 并连接实际状态依赖。随后明确：DMA 依赖解决后无需额外插入 barrier，
展开也自然给出每份实例的 program_id。采用这个方向作为后续统一 lowering 方案，使分组窗口
由实际 program 坐标及 index_map 的结果决定，不再逐一增加 `j//2`、`j//3`
等模式识别规则。这里是比较器内部的语义表示，不改写源 kernel 的执行策略。

例如 `grid=(12,129)`，首轴 parallel、末轴串行时，逻辑表示为：

```text
并行 p ∈ [0,12):
    K(p,0) → K(p,1) → … → K(p,128)
```

箭头是状态依赖的简写，不表示等待前一步所有异步工作完成，也不生成额外
barrier 节点；不同 p 之间不凭空加入顺序。两个轴都
parallel 时，形状为 `S` 的局部值可以表示为 `[12,129,*S]`，两个新增轴
是 program 轴。原 kernel 的 dot/reduce 等运算仍只操作原有局部维度；
最终输出按全局地址组装，不能直接把这些批量轴当作用户输出形状。

展开必须保留以下语义：

1. **地址绑定。** 显式展开时，每份实例的 grid 坐标就是其 `program_id`
   常量，无需另行推导；保留批量模板时使用有明确范围的 program 轴坐标。
   `num_programs` 保持原 grid 大小，index_map 代入同一组坐标，再与
   kernel 内局部坐标共同确定全局地址。批量化值
   不会复制共享 HBM 的存储身份；不同 program 的写重叠和通信依赖仍须证明。
   无法证明独立性的 parallel 访问不能直接视为互不相关的批量计算。
2. **状态传递。** 串行实例之间传递实际内存版本、初始化状态、适用作用域内
   的 scratch、信号量计数和在途 DMA。读后写、写后读、写后写及可观察
   副作用的必要顺序由图依赖保留；即使去掉额外 barrier，也不能丢掉这些顺序。
   DMA 的实际 start/wait 与信号量依赖保留，不能因结束一份实例就隐含完成
   DMA、清空信号量或补出源代码缺失的 wait。
   现有[长寿命输出 DMA 用例](../../../../tests/pallas_multi_output_cases.py)
   在第一个 program start、第二个 program wait，是该约束的具体正例；
   漏 wait 的路径仍必须拒绝。
3. **独立窗口。** 对每个输出分别计算实际映射块的序列。`j//2` 得到
   `0,0,1,1`，从而在 `0→1` 时结束旧窗口并建立新窗口。初始化和累加由
   kernel 代码决定；保留同一块不等于自动执行求和。切换时仍需证明写入覆盖、
   检查 DMA 引用，并遵守自动 staging 的连续同块访问约束。
4. **精确而有界。** 只展开预算内、静态可确定的串行坐标，数据值仍保持
   符号表达式。parallel 轴优先保留共享模板和符号坐标，不必实际复制
   12×129 份完整图。预算先于展开执行；未知数据依赖地址、不定长循环或
   未证明的并行依赖继续明确拒绝，不能以抽样执行代替证明。

实施前 `tensor_memory` 已有受限的串行重放和状态传递；缺口在于
`state_domains` 先要求输出可分解为拥有者轴与完全缺失的串行轴，窗口切换
也依赖这组轴。本轮复用已有状态解释器，让有界实例化后的实际地址序列
参与覆盖与窗口证明，并保留独立大 grid 的现有符号快速路径。地址、顺序和
资源生命周期仍归 core。用户进一步明确：**grid 展开只涉及语义图，不涉及
SymPy**。本轮生产改动仅在 core，展开、覆盖、逆映射、顺序及资源证明均不
调用代数后端。`IndexExpr` 的坐标代入属于 core 内部的整数索引计算。
后续调用者可以另行比较值表达式，但那不参与 grid 展开或决定其成功条件。

本轮验收包括 `j//2`、`j//3` 与拆分 grid 的规范化等价，内部循环的独立投影
与 CPU 对照，以及混合并行与串行、
多输出不同窗口、跨 program DMA 正例，以及缺初始化、错 map、漏 wait、
并行重叠写入、非连续同块复访和预算超限的反例。新策略统一 grid 展开的
表示方式，不自动补齐一般动态地址或远端通信协议的证明。

**本轮实现。** 保留整轴覆盖的符号快速路径；该证明不适用时，先检查串行
后缀的预算，再逐坐标代入 index_map。每个输出独立合并相邻、映射相同的
program，形成窗口；对剩余并行坐标复用矩形拥有者/逆映射证明。不同窗口的
全局矩形必须互不重叠，体积之和覆盖完整输出域；非连续复访、跨并行拥有者
的写重叠、漏块均拒绝。一般不规则并行像集仍需要额外证明，不能因为串行
坐标已知就假设并行部分也是一一映射。

`tensor_memory` 按实际窗口切换分别封存和失效输出。输入自动 staging
仍在每次 program 边界检查在途 DMA 的读源冲突；没有假定相同输入 map
就保证复用同一物理缓冲区。各实例中的 program_id 已替换为对应串行坐标，
num_programs 保持原 grid 大小，最终值按每个窗口的逆映射投影到全局输出。
没有新增 barrier，也没有为源代码补 wait。仅含信号量、没有数组 scratch
时也重放实际串行计数，并可跨输出窗口保留它；一维入口在已审查的覆盖或
状态限制处进入同一有界证明。

规则窗口使用固定大小、对齐的矩形格点去重证明互不相交，避免逐对比较
所有窗口；未满足这个充分条件时使用带预算的矩形交集检查。并行坐标保留
符号共享模板，串行数据值仍保持符号表达式。局部 dot/reduce 沿用原来的
输入形状和收缩/归约维度，program 轴不参与这些运算。验证包含 `2**24`
个并行拥有者、串行预算预检以及规则窗口的分析成本增长检查。

**普通信号量的执行绑定。** 锁定 JAX 0.11.2 的
[官方 TPU interpreter](https://github.com/jax-ml/jax/blob/32544801e26115ac1794926d027148abf3baf009/jax/_src/pallas/mosaic/interpret/interpret_pallas_call.py)
中，signal 未指定 core 时以 core 0 为目标，wait 消费当前 core 的计数。
因此普通 parallel grid 的 program_id 不能自动当作 core 编号。本轮源适配
保留显式 `core_index` 操作数；设备局部入口增加
`compare_pallas_kernels(..., check_protocol=True, execution_cores=1)`，表示调用方
明确把该执行绑定到本 device 的 core 0。这个条件保存在结果及 assumptions
中，验证证据时按相同条件重放，不能据此宣称任意 TPU 调度都成立。

已绑定单 core 时，可检查并行独立 program 的本地普通信号量；隐式目标和
显式 core 0 均可证明，core 1、错误计数、未清空计数仍拒绝。单 core 绑定
也不会为 parallel program 加入源代码没有的执行顺序。缺少绑定的并行
普通信号量继续拒绝；`execution_cores` 目前只接受 `None` 或整数 1。
任意多 core 的分配/路由、远端协议的 core 绑定仍未接入；该条件不传播为
普通代数入口的隐式环境假设。

新增用例见 [grid 展开案例](../../../../tests/pallas_grid_expansion_cases.py) 与
[回归测试](../../../../tests/test_pallas_grid_expansion.py)。覆盖分组正反例、不同
局部块形状、dot/reduce、DMA 代次/等待/覆盖、仅信号量跨窗口、单输出一维
入口、core 目标与执行条件重放，以及预算。CPU 对照开启 race、逻辑 bounds、
NaN 未初始化填充和 on_wait，检查两个种子的完整输出；这些结果与静态
证明分别报告，不是 TPU 实机验证。

**比较边界。** 分组轴与拆分轴可在 core 直接得到相同的输出表达式，并重放
normalized 证据。新增 grid 测试不调用 SymPy；错误 map/更新保留具体输出
反例，资源错误保留明确拒绝。内部循环用例与分组 grid 都完成地址/资源证明，
且投影与独立 NumPy 参考相符；本轮不将数值对照表述为这两个图的等价证明。
带 `program_id` 整数转浮点的内部循环仍生成不同的规范化表达式，额外代数
实验返回条件未决。尝试额外重放独立串行坐标后，代数查询仍超过 60 秒；
这项试验已撤掉，不按代数后端的接受情况改变 grid 展开策略。

**保留范围。** 新增的分组窗口要求静态串行后缀、已支持的 index_map 表达式
和无 padding 的矩形输出域；一般动态地址、不规则并行像集仍需专用证明。
独立并行轴保持符号，超出预算的串行展开明确失败。多 core 任意分配及路由
尚未实现，输入输出共享 HBM 仍按用户决定排除；这些条件不由 SymPy 补足。
