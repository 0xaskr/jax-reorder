# 核心工程原则

1. **结论可靠性优先。** 规范化必须保留声明范围内的语义，性能优化不能削弱判定标准。
2. **设计与实现相互对应。** 算法的支持范围、表示方式和反例在实现前或同时写入开发文档。
3. **证据留在仓库。** 决定、实验条件、复现命令和结果可供下一次 Agent 工作直接读取。
4. **逐层读取上下文。** 入口只保留导航和必要规则，细节放到相应领域文档。
5. **边界属于契约。** 不支持的输入和语义明确拒绝，错误匹配需要反例测试约束。
6. **脚本控制可重复执行。** AI 提出方案与解释，确定性工具记录执行、版本、预算、结果和停止条件。
7. **经验经过验证再沉淀。** 区分假设和已确认根因，把可复用判断写成范围明确的技能。
